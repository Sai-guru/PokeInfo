# ⚡ PokeInfo

PokeInfo is a fun and beginner-friendly web app built with **HTML**, **CSS**, and **vanilla JavaScript**. It uses the modern **`fetch()` API** to retrieve Pokémon data from the public [PokéAPI](https://pokeapi.co/) and displays key information like image, weight, height, and abilities.

---

## 🌟 Features

- 🔎 **Search Pokémon by name** (e.g., *pikachu*, *bulbasaur*)
- 🖼️ Displays **shiny Pokémon sprite**
- ⚖️ Shows **Weight** (in hectograms)
- 📏 Shows **Height** (in decimeters)
- 💥 Lists all **Abilities**
- ✅ Built using **fetch()** for API requests

---

## 🧪 Tech Stack

- HTML5
- CSS3
- JavaScript ES6
- `fetch()` API for making asynchronous API calls
- [PokéAPI](https://pokeapi.co/)
